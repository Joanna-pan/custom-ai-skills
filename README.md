# Custom AI Skills

A personal collection of reusable skills for Codex, OpenClaw, and compatible AI agents.

## Skills

### infographic-designer

Designs, creates, revises, and audits static infographics. Supports a five-axis morphological brief, direct and collaborative workflows, palette revisions, visual quality checks, and editable PNG, PPTX, and layered PSD deliverables.

Source: [`skills/infographic-designer`](skills/infographic-designer)

## Structure

Each skill is self-contained under `skills/<skill-name>/` and includes its `SKILL.md` entrypoint plus only the references, assets, scripts, and agent metadata it needs.
